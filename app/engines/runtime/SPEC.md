\# Runtime State Manager



\## Visione



Il Runtime State Manager rappresenta lo stato globale del Runtime di ARTECNA OS.



Non sostituisce gli Engine.



Non sostituisce i Workflow.



Descrive semplicemente in quale fase del Runtime ci troviamo.



\## Stati V1



\- created

\- event\_received

\- context\_updated

\- decision\_ready

\- waiting\_user

\- completed



\## V1



Nessuna persistenza.



Nessun database.



Nessuna UI.



Nessuna Action.



Serve esclusivamente come foundation del Runtime.
