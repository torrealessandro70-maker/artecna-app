# Sopralluogo Memory Engine

## Obiettivo

Costruire una rappresentazione unificata della conoscenza raccolta durante un sopralluogo.

## Principio

L'utente racconta il lavoro una sola volta.

Non importa dove.

Ogni informazione confluisce nella stessa memoria.

## Sorgenti attuali

- descrizione iniziale
- pagine del Quaderno

## Sorgenti future

- fotografie
- OCR
- documenti
- audio
- checklist
- planimetrie
- pin

## Output

SopralluogoMemory

Nessun Engine leggerà direttamente:

- descrizione
- quaderno
- fotografie

ma utilizzerà esclusivamente:

SopralluogoMemory
